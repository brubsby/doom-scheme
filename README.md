# doom-scheme

DOOM (linuxdoom-1.10) ported to Chez Scheme. See [DESIGN.md](DESIGN.md).

```sh
git clone --recursive git@github.com:brubsby/doom-scheme.git
nix develop
```

Target is linuxdoom-1.10 (`reference/doom/`); Chocolate Doom 3.1.1 (`reference/chocolate-doom/`) is a second reference. Both are git submodules.
